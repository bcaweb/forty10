# Forty10 Responsive Landing Page

This build is designed for desktop, tablet, and mobile screens.

## Open locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Responsive improvements
- Desktop navigation and layout preserved up to wide screens.
- Tablet layout changes at 1100px: menu becomes mobile-friendly and content stacks cleanly.
- Mobile layout changes at 720px and 420px: one-column services, compact hero artwork, readable headings, full-width CTA button, and no horizontal overflow.
- The hero artwork intentionally simplifies on very small phones so the Forty10 logo remains visible.

## Publish
Upload all files inside this folder to GitHub, Vercel, Cloudflare Pages, or any static web host.
